# 🎯 QuizArena — Інтерактивна платформа онлайн-тестів та квізів

Сучасний, швидкий та зручний веб-сайт для проходження тестів українською мовою з підтримкою **одиночного режиму (Solo)** та **мультиплеєрних лобі (Multiplayer Rooms)** у реальному часі.

🌐 **Демо на GitHub Pages:** [https://lukian656.github.io/quiz-arena/](https://lukian656.github.io/quiz-arena/)

---

## ✨ Основні можливості

- **🧠 Одиночний режим (Solo):**
  - Вибір кількості питань: **10, 20, 40** або всі доступні.
  - Категорії: Загальна ерудиція, IT & Програмування, Історія України, Наука & Космос, Географія, Кіно & Серіали.
  - Налаштування таймера: 15с, 30с або без обмежень.
  - Миттєвий підрахунок очок за швидкість та серію правильних відповідей.
  - Детальний розбір помилок з навчальними поясненнями.

- **👥 Мультиплеєр та Лобі:**
  - **Список активних публічних лобі** з живим пошуком та фільтрами.
  - **Створення власного лобі** (назва, категорія, кількість питань, час на відповідь, приватність).
  - **Приєднання за кодом кімнати** (наприклад, `Q-ABCD`).
  - **Кімната очікування (Waiting Room):** вибір аватарів, статус готовності, чат.
  - **Синхронна гра в реальному часі:** одночасний відлік часу, показ відповідей, живий лідерборд після кожного раунду.
  - **П'єдестал переможців** з конфеті та святковими звуковими ефектами.

- **🎨 Дизайн та UX:**
  - Чистий та сучасний інтерфейс (світла / темна теми).
  - Звукові ефекти через Web Audio API (не потребує зовнішніх аудіофайлів).
  - Адаптивність для смартфонів, планшетів і ПК.

## 🚀 Запуск локально (з Socket.io сервером)

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/lukian656/quiz-arena.git
   cd quiz-arena
   ```

2. Встановити залежності:
   ```bash
   npm install
   ```

3. Запустити сервер:
   ```bash
   node server.js
   ```

4. Відкрити в браузері: [http://localhost:3000](http://localhost:3000)
